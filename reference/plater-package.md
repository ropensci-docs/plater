# plater: Read, Tidy, and Display Data from Microtiter Plates

Tools for interacting with data from experiments done in microtiter
plates. Easily read in plate-shaped data and convert it to tidy format,
combine plate-shaped data with tidy data, and view tidy data in plate
shape.

plater defines a simple, plate-shaped file format for data storage, so
it's easy to remember the experimental design. The package provides
functions to seamlessly convert between that format and a tidy data
frame that's optimal for analysis.
[`check_plater_format`](https://docs.ropensci.org/plater/reference/check_plater_format.md)
is provided to help you manage plate-shaped files.  
  
You can work with purely plate-shaped data
([`read_plate`](https://docs.ropensci.org/plater/reference/read_plate.md)
and
[`read_plates`](https://docs.ropensci.org/plater/reference/read_plates.md)),
as well as with a combination of plate-shaped data and tidy data
([`add_plate`](https://docs.ropensci.org/plater/reference/add_plate.md)).
It further allows easy plate-shaped visualization of tidy data
([`view_plate`](https://docs.ropensci.org/plater/reference/view_plate.md)).
