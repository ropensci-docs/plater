## All functions

  : Read a plater-formatted file and combine it with an existing data
  frame.
- [`check_plater_format()`](https://docs.ropensci.org/plater/reference/check_plater_format.md)
  : Check whether a file is in plater format.
- [`read_plate()`](https://docs.ropensci.org/plater/reference/read_plate.md)
  : Read a plater-formatted file and turn it into a tidy data frame.
- [`read_plates()`](https://docs.ropensci.org/plater/reference/read_plates.md)
  : Read multiple plater-formatted files and combine result into one
  data frame.
- [`view_plate()`](https://docs.ropensci.org/plater/reference/view_plate.md)
  : Displays the data in the form of a microtiter plate.
